# ShopHub Admin Dashboard

Responsive management dashboard built with React, Vite, TypeScript, Tailwind CSS, pnpm, shadcn-style Radix primitives and Recharts.

## Run

```bash
pnpm install
pnpm dev
```

## Screens

Dashboard, orders, order details, products, add/edit product modal, delete confirmation, categories, category modal, customers, customer details, inventory, coupons and coupon modal, analytics with Recharts, reviews, shipping, payments, support tickets, users, roles/permissions, reports, audit logs, notifications and settings. Responsive sidebar converts to a drawer on mobile.
